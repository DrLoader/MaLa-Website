MaLa v2.0 Windows Compatibility

MaLa v2.0 is targeted at Windows 10 and 11. It is a 32-bit application and runs on both 32-bit and 64-bit Windows. Most features also run on Windows 7, but Windows 7 is not a supported version. Other versions of Windows may work, but are untested and unsupported.

  • On Windows 7, the optional visual styles for the settings screens (such as the dark theme) need Windows 10 or later and are switched off automatically.
  • Windows XP and older: MaLa v2.0 does not start (“not a valid Win32 application”). Please use MaLa v1.9.

MaLa v1.9 System Compatibility

MaLa v1.9 is for Windows XP and older. It won’t get any new features. Reported bugs will be looked at and fixed where possible.

  • Tested on Windows XP SP2 and Windows ME. Windows 98 and 2000 have not been tested.
  • Your existing settings, layouts, game lists and emulator setups are used as they are. Make a copy of your whole MaLa folder before upgrading, so you can go back if you need to.
  • Background music needs a CPU with SSE (Pentium III, Athlon XP or later). Preview videos need a video decoder for your video files; the Read Me in the download explains how to set one up.

MaLa v1.x maintenance: MaLa v1.9 is the final version of MaLa 1.x. No new features will be added to v1.x; reported bugs will be looked at and fixed where possible. MaLa v1.74 is available on request.
