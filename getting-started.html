Getting started with MaLa

► READ THIS FIRST MaLa doesn’t play games itself: MAME does. Get MAME running a game on its own first, then point MaLa at it. Most people who get stuck skipped that first step.

This page takes a new user from nothing to a game list in about 15 minutes. Already used MaLa 1.x? Follow the Read Me First in the download instead: it covers upgrading a copy of your old folder.

Step 1: get MAME working on its own

You need three things before MaLa can do anything.

  1. Windows 10 or 11. Most of MaLa runs on Windows 7, but it isn’t supported there. On Windows XP, use MaLa 1.9 instead.
  2. MAME, from mamedev.org, extracted into its own folder, for example C:\MAME.
  3. Your ROMs in MAME’s roms folder (C:\MAME\roms), as .zip files. ROM sets are tied to MAME versions: ROMs made for a much older MAME often won’t run in a new one.

Check it before going on. Open a command prompt in C:\MAME and type mame pacman, using any game you have. The game should start. If it doesn’t, MaLa can’t fix that: sort out MAME first. The MAME documentation and forums are the place for that.

Step 2: install MaLa

  1. Download the MaLa zip from the Download page.
  2. Before you extract it, right-click the zip, choose Properties, tick Unblock if it’s there, then OK. This stops Windows warning about every file inside.
  3. Extract the zip. Inside is a folder called MaLa2_00: copy everything in it into a new folder of its own, for example C:\MaLa. Don’t use Program Files, because MaLa saves its settings in its own folder.
  4. Start MaLa.exe. If Windows says “Windows protected your PC”, click More info, then Run anyway. MaLa isn’t code-signed, so Windows doesn’t recognise it yet. Your antivirus may also ask once.

The first time it starts, MaLa shows a short welcome and a What’s New window. Close them with any key.

Step 3: point MaLa at MAME

MaLa needs to know three things: where mame.exe is, where your ROMs are, and MAME’s own list of games (a file called mame.xml, which MaLa makes for you). Use a mouse and keyboard for this part; the joystick is for playing.

  1. Open Options. On the very first start MaLa says “This is your first start of MaLa” and opens Options by itself. Later, right-click anywhere in MaLa and choose Options.
  2. Go to the MAME Config tab, Basics. Beside MAME executable, click ... and pick C:\MAME\mame.exe. MaLa tells you which MAME it found.
  3. MaLa offers to create mame.xml, MAME’s list of every game it knows. Say Yes: it takes a minute or two with a modern MAME, and the Rom info file (XML) box fills in. If it didn’t ask, click Create beside that box.
  4. Beside Rom path, click ... and pick C:\MAME\roms. If a note about relative paths appears, click OK.
  5. Click OK. MaLa asks “Your configuration has changed! Refresh main game list?”. Say Yes: it builds All Games from the games whose ROMs it finds in your ROM folder.

You should now see a list of your games. If the list is empty, see Stuck? below.

Step 4: play

The keyboard keys MaLa uses out of the box; all of them can be changed in Options.

KeyDoes
Up / Down arrowsMove through the game list
Left / Right arrowsPrevious / next game list
1Start the selected game
2Open the MaLa menu
EscExit MaLa (it asks you to confirm)

To leave a game, use MAME’s own exit key (Esc by default). MaLa comes back with the game list where you left it.

Joystick or arcade controls: set them up in Options under the joystick and controller settings. A keyboard encoder (I-PAC and similar) sends keys, so it works with the table above as it is.

Step 5: add pictures and videos (optional)

MaLa shows a screenshot, marquee, control panel picture and preview video for each game when you have them. Nothing breaks without them.

  • In Options, MAME Config tab, Pictures and Videos: set the folders for Snap / Title, Marquee Pic, Control Panel Pic and Attract videos.
  • Name each file after the game’s ROM name: pacman.png, pacman.mp4. Videos can be .avi, .mp4 or animated .gif, with no codec packs needed.
  • Ready-made sets are available from sites such as Progetto-SNAPS and Arcade Database.

No pictures or videos showing? Check that Show pictures and Show videos are ticked in Options; Options says beside the folders when they’re off.

Other emulators

MaLa can launch almost any emulator, but you need to know how to start a game in that emulator from the command line first, with whatever options it needs. MaLa passes that same command for you; it can’t work it out for you.

Example: the Atari 2600 emulator Stella, with Stella in C:\Emulators\Stella and games in C:\Games\Atari2600.

  1. Test it on its own first. Open a command prompt and run one game: 
    "C:\Emulators\Stella\Stella.exe" "C:\Games\Atari2600\Thrust.bin"
    The game should start. If it doesn’t, fix that before going near MaLa.
  2. In Options, go to the Other Emu Config tab and click New under the emulator list.
  3. On Basics, fill in:
    • Name: Atari 2600
    • Executable: C:\Emulators\Stella\Stella.exe (the ... button browses)
    • Rom path: C:\Games\Atari2600
    • Rom extensions (separated by comma): bin,a26
  4. On Execution, the Command line is everything after the program name in your test. MaLa fills in the game for you: %path% is the ROM folder, %rom% the file name and %ext% its extension. For Stella the default is already right: "%path%\%rom%.%ext%".
  5. Presets fills in the command line for 63 common emulators; change it to match your test if yours differs.
  6. Click OK, then switch to the new emulator in MaLa and start a game.

MAME gets full help on this site. For other emulators, help is with plugging a working command into MaLa, not with setting up the emulator itself.

Stuck?

What you seeWhat to do
“Mame XML file not set!”MaLa doesn’t know where MAME is yet: Step 3.
The game list is emptyCheck the ROM folder in Options (Step 3), and that your ROMs match your MAME version (Step 1). By default MaLa lists only games MAME marks as working; untick that in Options to see the rest.
A game starts, then MaLa comes straight backRun the same game in MAME on its own (Step 1). If MAME can’t run it, MaLa can’t either.
“Windows protected your PC”More info, then Run anyway (Step 2).
No pictures or videosFolders and file names: Step 5.
MaLa locks up or closesSend the log (below).
